# Reports folder

The agent writes its human-readable output here. Do not edit these files by hand;
they are rewritten automatically (only when something actually changed).

| File | What it is |
|------|------------|
| `summary.md` | START HERE. Site-wide overview and the most important things to fix first. |
| `issues.csv` | Every issue found, one per row (open in Google Sheets / Excel). |
| `articles/*.md` | One report per article: issues, keyword ideas, link ideas, suggestions. |
| `search_console.md` | Only if Search Console is connected: CTR / position / cannibalization findings. |

Everything here is a SUGGESTION. The agent never edits or publishes your website.
